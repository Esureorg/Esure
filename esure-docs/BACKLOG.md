# Backlog and issue status

Active planning and implementation work is tracked in GitHub Issues, not in this
roadmap document.

## Maintained status links

- [Open and active issues (GitHub)](https://github.com/Esureorg/Esure/issues)
- [All issues, including closed items (GitHub)](https://github.com/Esureorg/Esure/issues?q=is%3Aissue)
- [Repository README: current MVP status](../README.md#current-mvp-status)

Use the GitHub issue tracker as the source of truth for whether work is planned,
in progress, closed, or superseded. Do not treat historical staging notes as
current commitments.

## Historical staging backlog
